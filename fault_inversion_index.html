⛰️ 断层形变反演工作台

Fault Deformation Inversion Workbench · 走滑与倾滑速率联合反演

本工作台基于弹性半空间位错模型，利用跨断层 GPS 速度剖面反演断层的运动学参数。通过非线性最小二乘拟合，可从平行与垂直断层方向的速度观测中分别提取走滑速率、倾滑速率、闭锁深度及断层倾角等关键信息。

下方提供数据准备说明，以及两个独立的反演工具。

走滑速率反演

平行于断层方向的速度剖面 · 螺旋位错模型
原理：采用 螺旋位错（screw dislocation） 模型描述走滑断层在弹性半空间中的形变场。断层两侧的平行速度分量满足反正切函数关系：
v∥(x) = (s/π)·arctan((x + c) / d) + v₀
其中 s 为走滑速率，d 为闭锁深度，c 为水平平移，v₀ 为垂直偏移。通过加权最小二乘拟合观测剖面，即可反演断层走滑运动学参数。

倾滑速率反演

垂直于断层方向的速度剖面 · 刃型位错模型
原理：采用 刃型位错（edge dislocation） 模型描述倾滑断层在弹性半空间中的形变场。垂直速度分量同时受断层倾角 θ 与闭锁深度 d 控制：
v⊥(x) = (s/π)·[cosθ·atan(u) + (sinθ − cosθ·u)/(1+u²)] + c₁
其中 u = (x + c₂ − d/tanθ) / d，s 为倾滑速率，θ 为断层倾角。该模型能同时约束倾滑速率与断层几何形态。
